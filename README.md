# PG and Hostel Website

A simple webpage for a fictional student PG and hostel, created using HTML and CSS.

## Sections
- Header and navigation
- Welcome banner
- Room options and sample prices
- Facilities list
- Address and contact details

## Flexbox practice
- `justify-content: flex-end` in the navigation bar
- `align-items: stretch` for room cards
- `flex-direction: column` for the facilities list
- `justify-content: center` for mobile navigation
- Column layout for room cards on small screens

## Files
- `index.html` - webpage content
- `style.css` - webpage design

## Run
Open `index.html` in a web browser.

## GitHub Pages
Upload `index.html` and `style.css` to a GitHub repository. Go to **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/(root)`, and save.

Note: Room prices, address and contact details are sample information. Replace them with your own project details if required.
